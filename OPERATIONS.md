# Operations

Copy `.env.example` to `.env`, replace secrets, run `scripts/bootstrap.sh` once, and apply `scripts/migrate.sh`. `start.sh` only starts and stops its own processes. The force-recreate seed is isolated behind `CONFIRM_DEMO_SEED=yes` and an explicit demo password.

The governed API is `/api/service-workflow`. Recurring occurrences are idempotent, evidence is hash-chained, inspections are deterministic, and supervisor acceptance is blocked by missing evidence, failed inspections, or open SLA exceptions. Apply migrations `003_service_billing_reconciliation.sql` and `004_service_photo_evidence.sql` before using the new billing and photo endpoints. Workforce offline sync, procurement, messaging, payroll/accounting adapters, provider invoice posting/payment receipts, and worker-privacy review remain external gates.

The `/service-runs` screen exposes tenant-scoped plans, occurrences, evidence metadata, inspection history, and exceptions. It caches run summaries and per-user checklist drafts for offline access. JPEG/PNG/WebP photos (up to 8 MB each, at most 25 queued per run) can be saved in this browser's IndexedDB while offline. The worker must sync pending photos after reconnecting; a queued photo is not server evidence. Sync uses a stable client upload ID, so retrying an uncertain response returns the original stored entry instead of duplicating the evidence chain. Once received, photos are stored in tenant-scoped database media with a checksum and evidence-chain entry; workers can retrieve them through an authenticated route. Browser storage can be cleared by the device or user, so unsynced photos need operational attention. The image content still needs inspection. Billing candidates compare an invoice digest and cited time/expense references with accepted work, then require a different supervisor to review them; they do not post invoices or verify payment. Critical checklist failures are ranked deterministically from up to 200 recorded inspections. An optional OpenRouter explanation must cite matching inspection IDs and is advisory to a supervisor; it does not claim to analyze photos.
